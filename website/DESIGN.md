# Visual Design System (DESIGN.md)

## Theme & Palette (Emerald Green System)

- **Mode**: Futuristic Sci-Fi Dark Mode
- **Base Background**: `#080a11` (Pitch Obsidian)
- **Surface Panels**: `#0e121e` (Semi-transparent obsidian glass)
- **Surface Hover**: `#141a2b`
- **Structural Borders**: `1px solid rgba(255, 255, 255, 0.08)`
- **High-Contrast Text**: `#f8fafc` (Slate 50)
- **Muted Text**: `#94a3b8` (Slate 400)
- **Primary Accent**: `#10b981` (Emerald 500)
- **Light Accent**: `#34d399` (Emerald 400)
- **Dark Accent**: `#059669` (Emerald 600)
- **Cyan Highlight**: `#38bdf8` (Cyber Cyan)

## Background Filter

- Background Banner (`/banner.jpg`): `filter: hue-rotate(125deg) saturate(1.35) brightness(1.05)`
- Ambient Radial Glows: Emerald gradient spots (`rgba(16, 185, 129, 0.18)`).

## Typography

- **Headings**: Inter / Space Grotesk
- **Code & Metadata**: JetBrains Mono
- **Body**: Inter

## Navigation

- Floating bottom command dock with conic scroll progress border (`#10b981` to `#34d399`).
- Mobile draggable action ball with expandable overlay menu.
